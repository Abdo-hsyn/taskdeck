# TaskDeck — Client

React 19 + TypeScript + Vite frontend for TaskDeck. See the [root README](../README.md) for setup, architecture, and the API contract ([docs/API.md](../docs/API.md)).

```bash
npm install
npm run dev      # http://localhost:5173 (proxies /api to :4000)
npm run build    # production build → dist/
```
